# 🚀 LeetCode Solutions

Welcome to my **LeetCode Solutions** repository! This repository contains my personal solutions to various LeetCode problems. I created this space to track my progress in Data Structures and Algorithms (DSA), practice problem-solving, and keep a well-documented log of my coding journey.

## 🛠️ Languages Used

The solutions in this repository are primarily implemented in:
- **Java** (Main language)
- **TypeScript**

## 📂 Repository Structure

All files in this repository are placed in the root directory and follow a clear, predictable naming convention to make it easy to find specific problems:

`leetcode[Problem Number] [Problem Name].[Extension]`

**Examples:**
- `leetcode121 Best Time to Buy and Sell Stock.java`
- `leetcode1292 Maximum Side Length of a Square with Sum Less than or Equal to Threshold.ts`

## 🌟 Why this repository?

- **Tracking Progress:** A visual representation of my consistency and problem-solving growth.
- **Reference:** A personal code library to revisit optimal approaches for standard DSA patterns (e.g., Dynamic Programming, Trees, Graphs, Two Pointers).
- **Helping Others:** Anyone practicing LeetCode is free to browse these solutions for hints, alternative approaches, or optimizations.

## 🚀 How to use this repo

1. Search for a problem by its **LeetCode Number** or **Name** using the GitHub search bar or your browser's "Find" shortcut (`Ctrl + F` / `Cmd + F`).
2. Click on the file to view the code.
